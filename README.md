# Vela

VPN-клиент для Windows, Android и iPhone на ядре [sing-box](https://github.com/SagerNet/sing-box).
Поддерживает подписки (Marzban, 3x-ui, Remnawave и другие панели) и ссылки
`vless://` (включая Reality, Vision, XHTTP и шифрование VLESS), `vmess://`, `trojan://`, `ss://`, `hysteria2://`/`hy2://`, `tuic://`, mKCP.
Серверы, которые sing-box не умеет запускать, работают на встроенном [Xray-core](https://github.com/XTLS/Xray-core).
Интерфейс на русском и английском.

## Что нового в 1.4

- **Движок Xray**: серверы с XHTTP, mKCP, шифрованием VLESS и конфигурации Xray JSON запускаются на встроенном Xray-core внутри sing-box. В списке такие серверы помечены значком «Xray».
- **Новые форматы подписок**: кроме списков ссылок (обычных и base64) Vela читает Clash/Mihomo YAML, sing-box JSON и Xray JSON. Серверы без ссылки сохраняются и работают как обычные.
- **Ссылки с сайтов провайдеров**: кнопка «Добавить в приложение» в личном кабинете открывает Vela. Понимает `vela://` и схемы других клиентов: `happ://`, `v2rayng://`, `v2rayn://`, `hiddify://`, `sing-box://`, `clash://`, `clashmeta://`, `mihomo://`, `flclash://`, `streisand://`, `v2box://`, `karing://`, `sn://`, `incy://`, `sub://`. Перед добавлением Vela показывает название, адрес и число серверов и спрашивает подтверждение.
- **Из буфера обмена**: скопировали ссылку на подписку или сервер — при открытии Vela предложит её добавить. Текст проверяется только на устройстве, одна и та же ссылка не предлагается дважды.
- **Режим «Только заблокированное»**: через VPN идут только сайты, заблокированные в России или закрытые для России (ChatGPT, Claude, Spotify, Netflix и другие), всё остальное напрямую. Списки обновляются при каждой сборке.
- **Объявления провайдера**: текст из подписки показывается баннером, который можно закрыть. Новое объявление появится снова.
- **Напоминания**: уведомления за 3 дня и за 1 день до окончания подписки, в день окончания и при расходе 90% трафика.
- **Статистика трафика**: график за 31 день, итоги по месяцам и за всё время. Хранится только на устройстве.
- **Активные соединения**: какие сайты и через какой сервер идут сейчас, с возможностью закрыть одно или все соединения.
- **Windows**: kill switch (без VPN интернет перекрыт, в режиме «Весь компьютер»), меню в трее с выбором сервера, маршрутизации и режима, горячая клавиша для подключения из любой программы, автообновление (проверка при запуске и раз в 6 часов, установка только по вашей команде).
- **Английский язык**: язык по системе или вручную (Системный / Русский / English).

## Что умеет

- **Подключение в одно касание**, а также автовыбор самого быстрого сервера с переключением при сбое.
- **Мгновенная смена сервера**: без переподключения, текущие соединения не рвутся.
- **Три режима маршрутизации**: «Умный» (российские сайты и IP напрямую, остальное через сервер; банки и госуслуги работают), «Только заблокированное» и «Весь трафик через VPN».
- **Блокировка рекламы** (кроме версии из Google Play: этого требуют правила Play для VPN) и свои списки доменов «всегда напрямую» и «всегда через VPN».
- **Подписки**: трафик, срок действия, автообновление по интервалу, который задаёт панель.
- **Проверка задержки**: при подключении реальная, через каждый сервер; без подключения по TCP.
- **Без утечек**: DNS через туннель (DoH), строгая маршрутизация TUN.
- **QR-коды**: добавление подписок и серверов с камеры, из фото или скриншота; «Поделиться» сервером, подпиской или всей настройкой.
- **Избранное, поиск и фильтры**: по стране, протоколу, рабочим серверам. Автовыбор берёт только избранные, если они есть.
- **Автопереключение**: если выбранный сервер перестал отвечать, Vela сама переходит на рабочий.
- **Раздельное туннелирование**: по приложениям на Android, по программам на Windows.
- **Инструменты**: график скорости, «Мой IP», тест скорости через выбранный сервер, журнал ядра.
- **Резервная копия**: экспорт и импорт одним текстом или QR-кодом между любыми устройствами.
- **Подписки**: обновление вручную одной кнопкой и автоматически с выбранным интервалом, отправка HWID для провайдеров с лимитом устройств, свой User-Agent.
- **Проверка серверов**: всех сразу (с кнопкой «Остановить») или одного нажатием на его пинг.
- **Для опытных**: свои правила маршрутизации, фрагментация TLS против простых блокировок, светлая и тёмная тема.
- **Windows**: режимы «весь компьютер» (TUN), «системный прокси» и «только локальный прокси», меню в трее, kill switch, горячая клавиша, автообновление.
- **Android**: виджет на главном экране, плитка в быстрых настройках, постоянный VPN (Always-on), открытие ссылок из мессенджеров.
- **iPhone**: Network Extension, переподключение без разрыва туннеля, «Постоянный VPN» (On Demand), виджет и кнопка в Пункте управления (iOS 18).

## Структура

```
core/        общая логика на Go: разбор ссылок и подписок, генерация конфигурации sing-box (с тестами)
xrayout/     движок Xray-core как outbound sing-box (XHTTP, mKCP, шифрование VLESS)
mobile/      обёртка core для gomobile (Kotlin и Swift вызывают её)
desktop/     клиент для Windows: Go + встроенное ядро + интерфейс в окне Edge/Chrome
android/     приложение Android: Kotlin, Jetpack Compose, VpnService
ios/         приложение iOS: SwiftUI + Packet Tunnel Network Extension (проект XcodeGen)
scripts/     сборка ядра для мобильных платформ
.github/     автосборка всех платформ в GitHub Actions
docs/        установка на телефоны, публикация в магазинах, материалы для Google Play
```

## Быстрый старт

### Windows

Запустите `Vela.exe`. Нажмите **Добавить сервер**, вставьте ссылку на подписку или сервер, затем **Подключить**.
Для режима «Весь компьютер» Vela попросит перезапуск от администратора: так работает любой VPN с виртуальным адаптером.
Без прав администратора можно выбрать в настройках режим «Только системный прокси».

Vela сама проверяет обновления (файл `version.json` в релизе **latest** на GitHub) и ставит новую версию по вашей команде.
Пока репозиторий закрытый, проверка у пользователей без доступа к нему не сработает.

Windows может показать «Система Windows защитила ваш компьютер», потому что файл не подписан.
Нажмите «Подробнее», затем «Выполнить в любом случае». Для публичного распространения купите сертификат подписи кода.

### Android: собрать APK без Android Studio

1. Создайте репозиторий на GitHub и загрузите туда эту папку.
2. Откройте вкладку **Actions** и дождитесь сборки, около 15 минут.
3. Скачайте файлы из релиза **latest** (раздел Assets) и установите на телефон `Vela-1.4.0-arm64-v8a-release.apk` (или `Vela-1.4.0-universal-release.apk`, если не уверены).

Сборок две. **full** — APK для установки с сайта: `Vela-1.4.0-arm64-v8a-release.apk`, `Vela-1.4.0-armeabi-v7a-release.apk`,
`Vela-1.4.0-universal-release.apk`. **play** — `Vela-1.4.0-play.aab` для Google Play, без блокировки рекламы.
Без секретов `ANDROID_KEYSTORE_*` сборки подписаны тестовым ключом. Как создать свой ключ и опубликовать приложение,
описано в [docs/google-play/GUIDE.md](docs/google-play/GUIDE.md), установка на телефон в [docs/INSTALL_PHONES.md](docs/INSTALL_PHONES.md).

Локально: Go 1.25+, JDK 17, Android SDK и NDK r28, затем `make android`.

### iPhone

Нужны Mac с Xcode и **платный** аккаунт Apple Developer: бесплатный не даёт права Network Extension.

```bash
./scripts/build-mobile-libs.sh ios
brew install xcodegen
cd ios && xcodegen && open Vela.xcodeproj
```

В Xcode выберите свою команду (Team) для обеих целей: Vela и VelaTunnel. Если Bundle ID `app.vela.client` занят,
поменяйте его и App Group в `ios/project.yml`. Затем запустите на подключённом iPhone.

## Разработка

```bash
make test       # тесты разбора ссылок и конфигураций (запускают настоящее ядро)
make windows    # dist/Vela.exe
make icons      # перегенерировать иконки
```

Чтобы переименовать приложение, поменяйте `Vela` в строках интерфейса, `applicationId` в `android/app/build.gradle.kts`,
`PRODUCT_BUNDLE_IDENTIFIER` в `ios/project.yml` и перегенерируйте иконки.
