# Как установить Vela на телефон

Готовый APK для Android и IPA для iPhone собирает GitHub Actions: бесплатный сервис, который компилирует проект на серверах GitHub. Ничего ставить на компьютер не нужно.

## Шаг 0. Загрузить проект на GitHub (один раз, около 10 минут)

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Установите [GitHub Desktop](https://desktop.github.com) и войдите в свой аккаунт.
3. Распакуйте архив **Vela-Android.zip** или **Vela-iOS.zip** в любую папку.
4. В GitHub Desktop выберите **File → Add local repository** и укажите распакованную папку. Программа предложит **create a repository**: согласитесь.
5. Нажмите **Publish repository**. Галочку **Keep this code private** можно оставить.
6. Откройте репозиторий на github.com и перейдите во вкладку **Actions**. Если GitHub спросит, разрешить ли workflows, нажмите **I understand…, enable them**.
7. Сборка запустится сама. Android собирается около 15 минут, iPhone около 25. Если сборка не стартовала, выберите слева нужный workflow и нажмите **Run workflow**.
8. Когда появится зелёная галочка, откройте сборку и внизу в разделе **Artifacts** скачайте файл.

> Через веб-интерфейс GitHub (кнопка «Upload files») скрытая папка `.github` с настройками сборки часто не загружается. Поэтому используйте GitHub Desktop или команды git:
> ```
> git init && git add . && git commit -m "Vela" && git branch -M main
> git remote add origin https://github.com/ВАШ_ЛОГИН/vela.git
> git push -u origin main
> ```

## Android

### Установка
1. Скачайте артефакт **Vela-android** и распакуйте его. Внутри `apk/release/`:
   - `Vela-1.1.0-arm64-v8a-release.apk` подходит почти всем телефонам с 2017 года;
   - `Vela-1.1.0-universal-release.apk` подходит любому телефону, если не уверены, берите его.
2. Перекиньте APK на телефон: через Telegram «Избранное», кабель или облако.
3. Откройте файл на телефоне. Android попросит разрешить установку из этого источника: **Настройки → Разрешить**.
4. Если Google Play Защита предупредит о неизвестном приложении, нажмите **Подробнее → Всё равно установить**. Приложение подписано тестовым ключом из проекта (`android/vela-test.jks`), а не через Google Play, поэтому предупреждение нормальное.

### Первый запуск
1. Откройте Vela и нажмите на созвездие или «Добавить сервер».
2. Вставьте ссылки на подписки, каждую с новой строки. Можно сразу несколько.
3. Нажмите на созвездие. Android спросит «Запрос на подключение»: нажмите **OK**. Разрешите уведомления: в шторке будет статус VPN.

### Чтобы VPN не отключался
- **Батарея:** Настройки → Приложения → Vela → Батарея → **Без ограничений**. На Xiaomi, Huawei, Honor и Samsung без этого система может выключить VPN в фоне.
- **Постоянный VPN** (по желанию): в Vela откройте Настройки → «Постоянный VPN» → включите Vela.
- **Плитка в шторке:** опустите шторку → карандаш → перетащите плитку **Vela**.

### Обновление
Установите новый APK поверх старого: подписки и настройки сохранятся. Все сборки подписаны одним тестовым ключом, поэтому обновление встаёт поверх. Если Android всё же пишет «приложение не установлено», удалите старую версию и установите заново (это случится, например, после перехода на свой ключ).

## iPhone (подпись своим сертификатом)

### Что нужно
- Сертификат с профилем (`.p12` + `.mobileprovision`) **с поддержкой Network Extension**. Без этого права iOS не даст запустить VPN. Почти все платные сертификаты, с которыми работают Shadowrocket и Happ, это право имеют.
- Программа для подписи: **ESign**, **Feather**, **KSign** или **Scarlet** на телефоне, либо **Sideloadly** на компьютере.

### Установка
1. Скачайте артефакт **Vela-iOS-unsigned-ipa** и распакуйте: внутри `Vela-unsigned.ipa`.
2. Подпишите IPA своим сертификатом. Пример для Feather или ESign:
   1. Импортируйте `.p12` (с паролем) и `.mobileprovision` в раздел сертификатов.
   2. Импортируйте `Vela-unsigned.ipa`.
   3. Нажмите **Подписать (Sign)**.
   4. **Важно:** не включайте опции вроде «Удалить расширения», «Remove PlugIns» или «Remove extensions». VPN работает именно в расширении `VelaTunnel.appex`, без него подключиться нельзя.
   5. Bundle ID можно оставить как есть или изменить: Vela найдёт своё расширение сама.
   6. Установите.
3. Для сертификата **разработчика** (Development) на iOS 16 и новее включите режим разработчика: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл., затем перезагрузка. Для Enterprise- и Distribution-сертификатов этот шаг не нужен.
4. Если приложение не открывается и пишет «Ненадёжный разработчик»: Настройки → Основные → **VPN и управление устройством** → выберите сертификат → **Доверять**.

### Первый запуск
1. Откройте Vela, нажмите «Добавить сервер» и вставьте ссылки на подписки, каждую с новой строки.
2. Нажмите на созвездие. iOS спросит «Vela хочет добавить конфигурации VPN»: нажмите **Разрешить** и подтвердите код-паролем или Face ID.

### Если не подключается
- Сразу после нажатия появляется ошибка «permission denied» или ничего не происходит. Значит, в профиле сертификата нет права Network Extension, либо при подписи удалилось расширение. Подпишите заново без удаления расширений, либо возьмите сертификат с поддержкой VPN.
- Сертификат отозван: приложение перестаёт открываться. Подпишите IPA новым сертификатом.

## Проверка серверов (все платформы)

В списке серверов нажмите значок спидометра. Vela сделает настоящий запрос через каждый сервер, тем же путём, что и ваш трафик, и покажет задержку. Для неработающего сервера появится причина: «порт закрыт», «сервер разорвал соединение», «отпечаток сертификата не совпал» и т.д.

- Причины видны полностью, если проверять **при отключённом VPN**.
- На Windows после проверки сохраняется отчёт `%APPDATA%\Vela\diagnostics.txt` (кнопка «Отчёт»). Его можно прислать для разбора.
- Переключатель «Сначала быстрые» поднимает рабочие серверы наверх.
